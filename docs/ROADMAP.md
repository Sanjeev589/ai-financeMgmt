# Implementation roadmap

1. Foundation: offline desktop UI, local database, module registry, privacy tests.
2. Receive the first menu name, input fields, actions, calculations, validations,
   and expected output from the user.
3. Implement that menu with synthetic test data, verify locally, commit source
   and documentation, and update the GitHub repository when available.
4. Repeat for each subsequent menu. Never publish application data.

No finance fields or business rules have been assumed in the foundation.
